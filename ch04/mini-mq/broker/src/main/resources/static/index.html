📨 한 건 보내기
메시지 (굵기 = 초당 건수) 컨트롤러 박동 + 메타데이터 복제 지도(메타데이터) 받기 = 라우팅 그룹 → 코디네이터 브로커 (박동·합류·커밋) 사본 칸: 꽉 참 ISR · 점선 ISR 밖 · ★ 리더 · 칸 위 화살표 = 복제 (주황 뒤처짐 · 빨강 ISR 밖)

📨 한 건의 여정

위의 "보내기"를 누르면 메시지 하나가 지나가는 단계가 여기 나온다. 자동 생산을 끄면 그림에서도 그 한 건만 보인다.
